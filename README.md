Mostly old DOS games, DOSBox, and small tools that do one job.

Lately it's been Terra Nova: Strike Force Centauri (Looking Glass, 1996):

- [terra-nova-plus](https://github.com/skw-1337/terra-nova-plus): mouse freelook, noclip, view distance and 16:9 from one launcher
- [terra-nova-viewer](https://github.com/skw-1337/terra-nova-viewer): fly around every map of the game in 3D, using your own game files
- [terra-nova-freelook](https://github.com/skw-1337/terra-nova-freelook): just the freelook, if that's all you want

Bugs, ideas, "doesn't work on my DOSBox": [discussions](https://github.com/skw-1337/terra-nova-plus/discussions).

Also [lan](https://github.com/skw-1337/lan), a small invite-only planner for our online LAN nights (CS 1.6, WC3, AoE2).
